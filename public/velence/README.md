# Velence fotók

Dobd ide a ház fotóit ezzel a névkonvencióval — automatikusan megjelennek a /velence oldalon:

- `velence-hero.jpg`  → teljes szélességű hero háttér (opcionális)
- `velence-01.jpg` … `velence-08.jpg` → galéria-helyek (a sorrend = a slotok sorrendje)

Támogatott kiterjesztés: jpg, jpeg, png, webp, avif.
Hiányzó fájl helyén igényes, márkahű placeholder jelenik meg (nem szürke doboz) —
a galéria hiányos fotókészlettel is jól néz ki.
